# یافتن اولین عنصر با `firstOrNull`

`firstOrNull(predicate)` عناصر را به ترتیب بررسی می‌کند و اولین عنصری را که شرط را می‌گذراند برمی‌گرداند. اگر موردی پیدا نشود، `null` برمی‌گرداند.

```kotlin
val firstAda = users.firstOrNull { user -> user.name == "Ada" }
println(firstAda?.id)
```

این متد از جست‌وجوی فهرست داخلی استفاده می‌کند و پس از اولین تطبیق متوقف می‌شود. برای نتیجهٔ احتمالی `null` از safe call یا بررسی صریح استفاده کنید.

اگر نوع عنصر خودش nullable باشد، `null` خروجی به‌تنهایی نمی‌تواند مشخص کند که مورد منطبق واقعاً `null` بوده یا هیچ موردی پیدا نشده است. در چنین حالتی، در صورت نیاز به تمایز، predicate یا مدل داده را طوری طراحی کنید که نتیجهٔ تطبیق را جداگانه نگه دارد.

**پیاده‌سازی:** `ICollection.firstOrNull` و `Collection.firstOrNull` در ماژول `collection/core`.
