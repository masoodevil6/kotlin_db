## Failures

### Observed Failure

`BuiltQuery.kt` حاوی package و پیاده‌سازی `QueryExecute` است، درحالی‌که مسیر و نام فایل متعلق به `BuiltQuery` در ماژول core است.

### Expected Behavior

ماژول core باید declaration قابل‌کامپایل `BuiltQuery` را در package تعریف‌شده برای core ارائه کند؛ کد `QueryExecute` باید در فایل و ماژول خودش باشد.

### Actual Behavior

`:data_base:core:compileKotlin` شکست خورد و Gradle پیش از اجرای تست‌ها متوقف شد.

### Minimal Reproduction

```text
.\gradlew.bat :data_base:core:test :data_base:manager:execute:test :data_base:migration:executor:test :data_base:query:executor:compileKotlin '-Pkotlin.compiler.execution.strategy=in-process' --no-daemon
```

### Relevant Source

```text
data_base/core/src/main/kotlin/query/reader/BuiltQuery.kt
data_base/manager/execute/src/main/kotlin/manager/QueryExecute.kt
```

هر دو فایل بررسی شدند؛ فایل دوم نیز با package `gog.my_project.data_base.manager.execute.manager` و class `QueryExecute` آغاز می‌شود. اصلاحی انجام نشد.

### Relevant Existing Test


### Root Cause

محتوای فعلی `BuiltQuery.kt` با هویت فایل، package مورد انتظار و typeهای موردنیاز core سازگار نیست. شواهد، ناسازگاری فعلی را ثابت می‌کنند اما نشان نمی‌دهند چه تغییر قبلی آن را ایجاد کرده است.

### Contract Impact

Build و verificationهای پایین‌دستی متوقف می‌شوند؛ قراردادهای پارامتر، CRUD، callback، ResultSet، generated key و DDL در این اجرا راستی‌آزمایی نشدند.

```text
Implementation Defect
```

این طبقه‌بندی به وضعیت فعلی source اشاره دارد و provenance تغییر را تعیین نمی‌کند.

### Minimal Correction Proposal

پیش از تکرار verification، محتوای `BuiltQuery.kt` باید با تعریف `BuiltQuery` در package درست تطبیق داده شود و منبع `QueryExecute` در فایل خودش باقی بماند. این فقط پیشنهاد است؛ source تغییر داده نشد و اصلاح به مجوز جداگانه نیاز دارد.
